# Frontend

The frontend of the **Cloud Policy Cost and Security Simulator**, a Digital Twin cloud simulation platform designed to help students, cloud learners, and beginner IT professionals gain practical experience in cloud governance, infrastructure monitoring, FinOps, and cybersecurity through an interactive web interface.

## ✨ Features

- Interactive cloud infrastructure dashboard
- Organization and tenant management
- Virtual Machine and Database simulation
- Real time resource monitoring
- AI assisted threat visualization
- Policy management interface
- Cost monitoring and forecasting dashboards
- Security alerts and analytics
- Learning labs and guided simulations
- User profile and settings management

## 🛠 Tech Stack

- React
- JavaScript (ES6+)
- Tailwind CSS
- PostCSS

frontend/

## 🚀 Getting Started

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm start
```

The application will be available at:

```
http://localhost:3000
```

## 📌 Notes

This frontend communicates with the Flask backend to provide a complete Digital Twin cloud simulation environment. It is actively developed as part of an undergraduate capstone project, with additional modules planned in the final development phase.
